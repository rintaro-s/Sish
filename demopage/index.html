Exclusive Commands Directory

二人だけの合言葉

退屈な標準コマンドを、妹への語りかけに変えて。 Sish独自のコマンド体系が、お兄ちゃんの開発効率を最大化します。

summon git clone

リポジトリをこの場所に召喚します。わざわざcloneなんて無機質な言葉、使わなくていいんだよ。

Usage: summon <repo>
void rm -rf

視界の邪魔なものをすべて虚無へ。私が跡形もなく消しておいてあげるから、お兄ちゃんは前だけ見てて。

Usage: void <path>
fiat sudo / exec

妹が権限を代行します。お兄ちゃんが「やれ」と言えば、それが世界のルール（命令）になるんだよ。

Usage: fiat <cmd...>
gaze ls -lahFt

ディレクトリの中身をじっと見つめます。サイズも属性も、お兄ちゃんのために見やすく整えておいたよ。

Usage: gaze [path]
lore backup copy

大切な記録（ファイル）のバックアップを作成します。お兄ちゃんのこれまでの歩み、私が守ってあげる。

Usage: lore <path>
genesis git init & add & commit

すべてのはじまり。リポジトリの初期化から最初のコミットまで、私が一気にやっておくね。

Usage: genesis <dir>
oracle chmod +x

ファイルに実行権限という「命」を吹き込みます。これでこのスクリプトもお兄ちゃんのために動けるようになるよ。

Usage: oracle <path...>
